#  Percentile-based Thinking

هرگز با **Average**  کار نکنید. در خیلی از موارد، یک سری داده ( که ممکن است تعداد آن ها بسیار اندک می باشد) در میانگین تاثیر زیادی گذاشته و عدد میانگین را از عدد واقعی بسیار دور می‌کنند. از طرف دیگر، اگر بیشتر درخواست‌ها سریع باشند ولی درصد کمی خیلی کند باشند، average ممکن است هنوز قابل قبول دیده شود، در حالی که کاربران واقعی اذیت می‌شوند. برای همین در سیستم‌دیزاین و production monitoring از percentile استفاده می‌کنیم.  عموما به جای میانگین  از درصد های زیر برای performance استفاده می کنیم

| Percentile | نوع | معنی |
|---|---|---|
| P50 | تجربه کاربر معمولی | یعنی ۵۰٪ درخواست‌ها سریع‌تر از این مقدار جواب گرفته‌اند<br>P50 = 100ms یعنی نصف request ها زیر ۱۰۰ میلی‌ثانیه بوده‌اند. |
| P90 | کاربران سنگین | یعنی 90 درصد درخواست‌ها سریع‌تر از این مقدار جواب گرفته‌اند |
| P95 | اکثر کاربران | یعنی 95 درصد درخواست‌ها سریع‌تر از این مقدار جواب گرفته‌اند<br>این معمولاً برای SLO خیلی استفاده می‌شود. |
| P99 | بدترین تجربه‌ها | یعنی 99 درصد درخواست‌ها سریع‌تر از این مقدار جواب گرفته‌اند |

## چرا P95 و P99 مهم‌تر از Average هستند؟

چون مشکل واقعی معمولاً در tail latency است. Tail latency یعنی کندترین بخش درخواست‌ها. تصور کنید endpoint زیر را داریم:

```
P50: 80ms
P90: 200ms
P95: 600ms
P99: 4s
```

این یعنی اکثر کاربران تجربه خوبی دارند، اما بدترین ۱٪ تجربه بسیار بدی دارند.

حالا چرا این مهم است؟ چون در سیستم‌های مدرن، یک درخواست کاربر ممکن است به چند سرویس دیگر وابسته باشد.

مثلاً request باز کردن صفحه home در Uber:

```
User API
Pricing API
Driver Location API
Map API
Promotion API
Payment API
```

اگر هر کدام از این سرویس‌ها P99 بدی داشته باشند، احتمال اینکه کل request کند شود بالا می‌رود.

به این می‌گویند:  Tail Latency Amplification یعنی کندی‌های کوچک در سرویس‌های مختلف جمع می‌شوند و تجربه نهایی کاربر را خراب می‌کنند.

 استاندارد حرفه‌ای: SLO روی Mean تعریف نمی‌شود

- SLO روی P95 یا P99 تعریف می‌شود
- نه روی Mean

چون average نمی‌گوید چند درصد کاربران تجربه بد دارند. یک SLO حرفه‌ای معمولاً این شکلی است:

```
For /payment/authorize:
P95 latency < 400ms
Error rate < 0.1%
Availability > 99.9%
```
